# Brand

The kit uses the GEOwallah editorial field-manual style: cream paper, ink text, one burnt-orange accent, a deep green for evidence.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#17130f` | Text, dark sections |
| Paper | `#fffdf8` | Background |
| Cream | `#f4eee2` | Panels, section backgrounds |
| Cream 2 | `#ebe3d3` | Table headers, chips |
| Line | `#d8cebd` | Borders |
| Muted | `#6d645a` | Secondary text |
| Accent | `#c9430a` | Links, rules, one CTA |
| Accent soft | `#fbe9df` | Callouts |
| Green | `#1e4b39` | Evidence, success |
| Green soft | `#e7efe9` | Evidence panels |

## Type

- **Display:** Iowan Old Style, Palatino Linotype, Palatino, Georgia, serif.
- **Text:** Segoe UI, system-ui, -apple-system, Helvetica Neue, Arial, sans-serif.
- **Mono:** Cascadia Mono, Consolas, Courier New, monospace.

No external font files. The system stack keeps the page fast and portable.

## Voice

- Direct, practical, slightly contrarian.
- No hype. No "in today's fast-paced world."
- Short sentences. Concrete nouns. One idea per paragraph.
- Say what you would do, and why.
- Name the trade-off.

## Logo

The wordmark is text: **SEO Agent Kit** with a small **by GEOwallah** line. Do not use the GEOwallah logo without permission. A text credit with a link is always fine.

## Usage

- Keep the palette and type consistent.
- Do not add a second accent colour.
- Do not use emoji as icons.
- Do not use stock photos of people shaking hands.
- If you fork the repo, keep the credit line in `CREDITS.md` and the landing page footer.
