# The 120-point audit

Score each item pass/fail. Do not average across categories. A failed indexability or compliance item is a STOP.

## Crawl and index (12)

- [ ] robots.txt returns 200 text/plain
- [ ] robots.txt does not block money pages
- [ ] sitemap.xml is valid XML
- [ ] sitemap contains only canonical URLs
- [ ] sitemap submitted in GSC
- [ ] money pages indexed
- [ ] no accidental noindex
- [ ] canonicals are self-referencing
- [ ] one host/protocol/slash convention
- [ ] no redirect chains over one hop
- [ ] missing pages return 404/410
- [ ] no soft 404s returning 200

## Rendering and speed (12)

- [ ] primary content in server HTML
- [ ] internal links crawlable without JS
- [ ] LCP <= 2.5s at p75
- [ ] INP <= 200ms at p75
- [ ] CLS <= 0.1 at p75
- [ ] TTFB under 800ms at p75
- [ ] hero image prioritised
- [ ] images use modern formats
- [ ] images have dimensions
- [ ] fonts subset and swapped
- [ ] no unused heavy scripts
- [ ] third-party tags audited

## On-page (12)

- [ ] one H1 per page
- [ ] H1 matches intent
- [ ] title under ~60 characters
- [ ] title includes the query shape
- [ ] meta description is specific
- [ ] description length 120-160
- [ ] answer in first 60 words
- [ ] headings form a logical outline
- [ ] no keyword stuffing
- [ ] images have descriptive alt
- [ ] internal links are contextual
- [ ] external links are sourced

## Content and E-E-A-T (12)

- [ ] named author with bio
- [ ] author has external profiles
- [ ] first-hand experience shown
- [ ] original data or examples
- [ ] claims cite primary sources
- [ ] statistics dated
- [ ] about page has legal entity
- [ ] contact page is real
- [ ] methodology page for data
- [ ] corrections policy exists
- [ ] reviews are genuine
- [ ] no fake awards or logos

## Architecture and internal links (12)

- [ ] money pages within 3 clicks
- [ ] every spoke links to its pillar
- [ ] every pillar links to its spokes
- [ ] breadcrumbs on deep pages
- [ ] no orphan money pages
- [ ] descriptive anchor text
- [ ] 3-6 contextual links per 1,000 words
- [ ] no sitewide footer link spam
- [ ] category pages link to products
- [ ] products link to categories
- [ ] related content is relevant
- [ ] click depth audited quarterly

## Schema and entities (12)

- [ ] Organization schema
- [ ] WebSite schema
- [ ] BreadcrumbList schema
- [ ] Article schema on editorial
- [ ] Product schema on products
- [ ] LocalBusiness on local sites
- [ ] Person schema on authors
- [ ] no fake reviews in markup
- [ ] markup matches visible content
- [ ] Rich Results Test passes
- [ ] sameAs links are accurate
- [ ] schema updated when facts change

## AI search and GEO (12)

- [ ] 10 money pages citation-scored
- [ ] answer-first on all money pages
- [ ] 3+ sourced statistics per page
- [ ] 1+ named quotation per page
- [ ] comparison page per cluster
- [ ] original data asset per quarter
- [ ] entity consistency across web
- [ ] Reddit presence is real
- [ ] YouTube presence where relevant
- [ ] reviews and directories current
- [ ] GSC AI report reviewed
- [ ] 30-prompt panel logged weekly
