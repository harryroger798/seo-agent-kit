How it works

Three questions. Two checkpoints.

The agent does not start with a template. It starts with your site, your outcome, and the tools you actually have.

01

Clone or paste

Open the repo in Claude Code, Cursor, or Codex. No repo access: Paste BOOTSTRAP.md into any assistant.

02

Answer three

Site, outcome, tools connected. If a tool is missing, the agent says so and asks for a CSV. It does not invent data.

03

Run one pipeline

Brief approval, publish approval. A QA list with every [VERIFY] item. One metric, one date.

Cite or cut.

Every statistic, quote, price, and competitor claim needs a source and a date. If it cannot be sourced, it does not ship. No invented experience. No keyword density. One product link.

Start

Five minutes to your first pipeline.

Clone the repo, open it in your agent, and paste the bootstrap prompt.

git clone https://github.com/harryroger798/seo-agent-kit.git
cd seo-agent-kit
python scripts/validate_kit.py
Read AGENTS.md and kit.json.
Then read skills/seo-orchestrator/SKILL.md.
Ask me the three intake questions before doing anything:
1. Which site or product URL:
2. What is the one outcome for this sprint:
3. Which tools are connected: Ubersuggest MCP, AnswerThePublic,
   SpyFu, Mangools, GSC, GA4, or manual/CSV:
Do not research, write, submit, or publish until I answer.
