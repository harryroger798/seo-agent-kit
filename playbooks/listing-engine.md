# The listing engine

A product page is a trust document. For digital goods, it has to replace the inspection the buyer cannot perform.

## Anatomy

| Element | Standard | Why |
|---|---|---|
| Title | 60–70 chars, product + differentiator | Snippet and card |
| Focus keyphrase | 1 primary, 2–3 secondary | Prevents targeting everything |
| Short description | 150–160 chars | Meta and card |
| Long description | 800–1,500 words | Education and long-tail |
| Comparison table | 3–5 real alternatives | Commercial queries and AI answers |
| FAQ | 5–7 real questions | Objections and snippets |
| Delivery | Exact method and time | #1 anxiety |
| Validity | Duration, renewal, region, device limit | Prevents disputes |
| Meta + slug | 150–160 chars; 3–5 words | CTR and canonical |
| Category + tags | One real category; 5–7 tags | Discovery |
| Images | Main + 4 supporting, with metadata | Conversion and image search |
| Video | One demo, below the hero | Shows the product |

## The trust layer

- What exactly do I get?
- How is it delivered?
- How long does it last?
- Will it work in my region?
- What if it fails?
- Are you authorised to sell it?

## The five images

1. **Main** — product interface on a clean device, no invented UI text.
2. **Sale** — the actual offer, no fake percentage.
3. **Value** — what you get, grid or comparison.
4. **Delivery** — inbox or dashboard with an order confirmation, no personal data.
5. **In action** — a real workflow, not a stock hand.

For each: prompt, ALT, title, description, ratio, placement.

## Compliance

- No “official,” “authorised,” or “genuine” without proof.
- No accounts or keys in violation of the vendor’s terms.
- No “lifetime” when you mean “until the plan changes.”
- No fake discounts, reviews, or scarcity.
- No trademark use that implies endorsement.

## QA

- [ ] Title 60–70 chars.
- [ ] Focus keyphrase in title, H1, first 100 words, meta.
- [ ] Short description 150–160 chars.
- [ ] Long description answers what/who/how/how long.
- [ ] Comparison table verified.
- [ ] FAQ covers delivery, validity, compatibility, refund, support.
- [ ] Product schema matches visible facts.
- [ ] Five images with alt text.
- [ ] No fake reviews, discounts, or “official” claims.
- [ ] Support and policy pages linked.
