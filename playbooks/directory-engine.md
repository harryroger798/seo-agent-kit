# The directory engine

A directory listing is a citation with a form. The goal is verified live listings where the buyer looks, not submissions everywhere.

## The seven steps

| # | Step | Action | Output |
|---|---|---|---|
| 1 | Queue | Pick next site; set In progress | One site, one owner |
| 2 | Brief | Tagline ≤60, short ≤160, long 120–200, category | Brief |
| 3 | Contact | Find founder/email; never guess | Verified contact |
| 4 | Inbox | Test access before submitting | Tested inbox |
| 5 | Assets | Logo, screenshots, demo | Asset pack |
| 6 | Submit | Duplicate check first; batch of 15 | Submission log |
| 7 | Verify | Click confirmation; set Live; record URL | Verified listing |

## Status taxonomy

`To do` · `In progress` · `Submitted` · `Live` · `Skipped` · `Failed` · `Already listed`

## Tiering

| Tier | Criteria | Batch |
|---|---|---|
| A | Relevant, editorial, real traffic, dofollow or strong referral | First 15 |
| B | Niche directories with curation and a free tier | Next 30 |
| C | Low-cost citations; free, indexed, low traffic | Capped |
| Skip | Paid-only, badge required, dead, spam, irrelevant | Zero |

## Duplicate check

1. `site:directory.com "yourdomain.com"`
2. Search the product name.
3. Check the category page.
4. If found: `Already listed`, record URL, stop.
5. If not: submit once.

## Verification

A submitted listing is not a live listing. Click the confirmation email. Load the public URL. Record it. If the URL 404s or the listing is pending, keep the status `Submitted`.

## The 90-day rule

Directories decay. Re-check every live listing after 90 days. Mark removed or dead listings `Failed`. Replace them with a better target.

## Rules

- Free listings only.
- One site fully processed before the next.
- No duplicate submissions.
- No paid listings without approval.
- No badge requirements unless approved.
- Record every status change immediately.
