## The directory list

The full 687-directory list lives in Notion. The kit does not ship it because it is yours and it changes. To pull it:

1. Set `NOTION_TOKEN` and `NOTION_DATABASE_ID` in `.env`.
2. Run `python scripts/import_notion_directories.py --site yourdomain.com`.
3. Validate with `python scripts/directory_dedupe.py data/directories.csv`.

See `docs/10-import-notion-directories.md`.

## Private data

Do not commit client exports, emails, phone numbers, order data, or API keys. Use `data/private/` (gitignored) for anything sensitive.
